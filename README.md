# 语雀 Markdown 导出器

一个纯本地 Chrome Manifest V3 扩展，用于识别当前打开的单篇语雀文档、表格（Sheet）或数据表/看板，并查看、复制或导出对应的 Markdown。表格和数据表还可导出 CSV。

## 项目背景

企业语雀知识库通常只能在线查看，部分空间不提供文档导出能力。这使得需求文档难以作为本地文件交给 Agent 进行梳理、分析和理解，也增加了手工复制内容的成本。

语雀文档地址追加以下路径和参数后，可以直接查看 Markdown 原文：

```text
/markdown?plain=true&linebreak=false&anchor=false
```

本扩展将这一操作封装为浏览器内的一键功能：自动识别当前语雀文档，支持查看、复制和导出 Markdown，并可选择将远程图片一并下载到本地。扩展只处理用户当前登录态下本来有权访问的文档，不绕过语雀的身份认证或访问权限。

语雀的表格（Sheet / Excel）和数据表/看板虽然使用与普通文档相似的 URL，但没有对应的 `/markdown` 地址，请求会返回 HTTP 404。表格文档会通过当前登录态读取语雀已经解密的表格 JSON（`body_sheet` / Lakesheet），包含全部工作表，再转成 Markdown 或 CSV。数据表/看板仍按当前表格视图采集页面已渲染的记录；其接口如果返回完整记录，也会作为采集失败时的兜底。扩展不破解密文，也不读取登录凭证本身。

## 功能

- 自动识别 `yuque.com` 和企业语雀子域名中的单篇文档。
- 在新标签页查看 `/markdown?plain=true&linebreak=false&anchor=false` 原文。
- 一键复制 Markdown。
- 导出单个 `.md` 文件，图片保持语雀原地址。
- 下载远程图片、改写为 `images/...` 相对路径并导出 `.zip`。
- 单张图片下载失败时继续导出，并保留该图片的原地址。
- 识别语雀表格（Sheet / Excel），把全部工作表导出为 Markdown 或 CSV，不依赖 `/markdown` 地址。
- 识别语雀结构化数据表/看板，避免将 `/markdown` 的 404 误报为权限问题。
- 从看板临时切换到已有的“表格视图”，采集完成后恢复原视图。
- 导出表格视图当前筛选、分组和排序结果为 Markdown 或 CSV。
- 虚拟滚动逐批采集并去重；无法确认完整性时不生成残缺文件。

当前版本只支持当前单篇文档或单个结构化表格，不支持整本知识库批量导出。

## 安装

1. 下载或克隆本仓库。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的仓库根目录。
6. 建议将“语雀 Markdown 导出器”固定到浏览器工具栏。

## 使用

### 普通文档

1. 登录语雀并打开一篇有权访问的普通文档。
2. 点击扩展图标，确认显示“已识别语雀文档”。
3. 选择需要的操作：
   - **查看 Markdown**：在新标签页打开 Markdown 原文。
   - **复制 Markdown**：写入系统剪贴板。
   - **保持图片原地址**：导出 `<文档标题>.md`。
   - **下载图片到本地**：先分析图片域名，点击“授权并导出”后生成 `<文档标题>.zip`。

ZIP 中包含 `<文档标题>.md` 和 `images/`。同一个远程图片只下载一次；无法读取的图片继续使用远程地址，弹窗会显示成功和失败数量。

### 表格或数据表

1. 打开一个有权访问的语雀表格、数据表或看板。
2. 点击扩展图标，确认显示“已识别语雀表格/看板”。
3. 选择“查看 Markdown”“复制 Markdown”，或选择导出格式：
   - **Markdown 表格**：适合发送给 Agent 阅读和分析。
   - **CSV 表格**：适合 Excel 或其他数据处理工具。
4. 打开的是表格（Sheet）时，扩展读取该工作表的完整数据。
5. 打开的是数据表/看板时，扩展会临时切换到已有的“表格视图”，按当前筛选逐批采集后恢复原视图。

导出范围是该“表格视图”自身当前保存的筛选、分组和排序结果。看板与表格视图可以拥有不同的筛选配置，因此从看板触发不代表导出看板当前筛选的底层全部记录。扩展不会自动清除筛选条件。

## 权限说明

- `activeTab`：只在点击扩展时读取当前标签页地址和标题。
- `clipboardWrite`：执行“复制 Markdown”。
- `scripting`：用户主动使用扩展时，向当前语雀标签页临时注入表格识别和采集代码；不会常驻注入所有网页。
- 语雀 `http(s)://yuque.com/*` 及其子域名：使用当前语雀登录态读取 Markdown。
- 可选的 HTTP(S) 图片域名权限：仅在选择“下载图片到本地”后，根据文档实际引用的域名申请。拒绝不会影响保持原地址的 `.md` 导出。

扩展不会上传、同步或持久化文档/表格内容，不读取 Cookie、Authorization、Token、Local Storage 或浏览历史，也不会修改语雀原文、记录或筛选设置。生成的 Markdown 预览只在扩展后台内存中短暂保存，读取一次或 60 秒后失效。

## 开发与测试

要求 Node.js 20 或更新版本。项目没有第三方运行时依赖。

```bash
npm test
```

自动化测试覆盖 URL 识别、文件名、图片解析与改写、错误处理、图片本地化、ZIP32 结构、表格 JSON 解析、表格格式化、虚拟滚动去重、冲突和超时保护、弹窗工作流、本地预览安全性及扩展包完整性。

## 已知限制

- 不支持知识库批量导出、定时同步和附件下载。
- 语雀表格（Sheet）通过当前登录态读取文档 JSON 并解压 Lakesheet；不依赖页面虚拟滚动。接口不可用时会明确失败，不生成残缺文件。
- 数据表/看板会读取当前视口中语雀分别渲染的固定列、字段列等表格窗格，必要时遍历横向分段，并按屏幕几何位置合并为记录；只有在能够证明行列对齐、稳定识别记录且滚动到末尾后才会生成文件。无法证明时会尝试接口完整记录，仍失败则不输出残缺文件。
- 结构化页面依赖语雀当前的表格 DOM 结构；语雀大版本升级后可能需要更新适配。失败提示下的“诊断信息”只包含匿名 DOM 形状，保存在当前标签页和弹窗内，不会上传到任何服务，可展开复制后用于排查。
- v2 通过表格视图统一导出，不还原原始看板的列布局，也不会自动清除筛选导出底表全部记录。
- 公式只导出页面当前显示值，不导出公式逻辑；评论、记录历史和附件二进制内容不在导出范围内。
- 只解析标准 Markdown 内联图片和带引号 `src` 的 HTML `<img>`。
- 用户关闭弹窗后，尚未完成的导出不保证继续运行。
- 部分受防盗链、短时签名或网络策略保护的图片可能无法下载；此时保留原 URL。

修改源码后，请在 `chrome://extensions/` 点击扩展的“重新加载”，再刷新语雀页面。旧的 content bridge 仍可能留在已打开的标签页中，仅刷新页面不会加载最新扩展代码。
